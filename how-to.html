How to use this planner

Recognized public methods only. We do not claim medical advice or ADHD treatment.

Methods credited

MethodHow it appears here
Time blocking (Cal Newport–style framing as a method name)Each day has Morning / Afternoon / Evening blocks — put one job in a block, not a floating to-do list
MIT / Top 3（一日三件事）Three checkboxes max per day. If everything is #1, nothing is
Pomodoro (Francesco Cirillo)Four tick circles ≈ four 25-min focus sessions; take a break after a tick
Eisenhower (optional weekly)On Weekly review: Urgent/Important quadrants for Sunday reset

Daily loop (under 5 minutes to set)

  1. From Year → Month → Week.
  2. Write at most 3 MITs for today.
  3. Drop each MIT into a time block (or park one in Brain dump).
  4. Run Pomodoro ticks; mark boxes when done.
  5. Sunday: open Weekly review once.

Browser / GoodNotes / print

  • Browser: open index.html (or the GitHub Pages URL). Links are relative — keep the folder intact.
  • Print / PDF: File → Print → Save as PDF (print CSS reduces clutter).
  • GoodNotes / Notability: import the PDF, or screenshot week spreads. Hyperlinks work best in browser; PDF may flatten some links depending on your app.
