# ADHD 2027 Hyperlinked Digital Planner (Free Sample)

**What:** A working **2027** hyperlinked HTML planner — **12** month hubs → **53** week spreads → blank day template. Each day: **Top 3** (MIT), **3** time blocks, **4** Pomodoro ticks.

**Who for:** Adults with ADHD (self-described) who lose the plan by late morning and want **one screen per day** — not a 200-page aesthetic dump, not a medical program.

**Price:** **$0**. Clone / browse / print. No signup.

**Why trust:** Built on named public methods (below), not one person’s private diary. Includes a clearly marked **EXAMPLE** filled week (fake persona **Alex Rivera**). Public repo + MIT License. AI-assisted packaging disclosed.

**After click:** Open [`index.html`](index.html) (or the GitHub Pages URL) → How to use → EXAMPLE week → pick a 2027 month → open a week spread.

## Methods credited (public)

| Method | How it appears here |
|--------|---------------------|
| **Time blocking** (Cal Newport–style framing as a method name) | Morning / Afternoon / Evening blocks on every day |
| **MIT / Top 3**（一日三件事） | Three checkboxes max per day |
| **Pomodoro** (Francesco Cirillo) | Four tick circles ≈ four 25-min focus sessions |
| **Eisenhower** (optional) | Weekly review quadrants |

We do **not** claim ownership of these methods or any medical/ADHD-treatment effect. We wrote the HTML structure, navigation, EXAMPLE content, and copy in this repo under the MIT License (`LICENSE`).
